Rodz provides intent‑based buying‑signal data to help software vendors, agencies, and sales teams discover the right contacts at the right time. Their platform ingests public and proprietary signals, enriches them, and makes them searchable via an API, enabling integration into CRMs and outreach tools. Rodz aims to improve lead quality and accelerate sales cycles through real‑time intent data.

**Areas:** B2B · Sales · IntentData · LeadEnrichment · API

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Rodz: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
